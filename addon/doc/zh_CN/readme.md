# 窗口状态

一款 NVDA 插件，用于查询当前前台窗口的状态。

## 问题

NVDA 在查询窗口标题时，不会告知您窗口是最大化、还原，还是贴靠到屏幕一侧。这些信息很有用，因为：

- 按 Windows+上光标最大化窗口时，可能触发 Windows 11 的贴靠布局选择器，使窗口处于未知状态。
- 明眼用户只需扫一眼就能看到窗口的大小和位置。而盲人用户没有相应的核对方式，只能尝试调整窗口大小，并听 NVDA 的语音提示。
- JAWS 在其 JAWS+T 标题播报中包含了这些信息，而 NVDA 没有。

## 此插件的作用

1. **NVDA+Shift+T**：读出当前前台窗口的状态。可能的状态包括：
   - 最大化
   - 还原（普通窗口模式）
   - 最小化
   - 左侧贴靠、右侧贴靠、顶部贴靠、底部贴靠（半屏贴靠）
   - 左上四分之一、右上四分之一、左下四分之一、右下四分之一

2. **可选的 NVDA+T 增强**：在设置中启用后，按 NVDA+T 将读出窗口标题后跟状态，例如“Firefox, 最大化。”此行为与 JAWS 一致。按 NVDA+T 两次逐字朗读标题、按三次复制到剪贴板的功能不受影响。

## 设置

打开 NVDA 设置 > 窗口状态进行配置：

- **按 NVDA+T 读出标题时追加窗口状态**：选中后，会在按 NVDA+T 读出标题时包含窗口状态信息。默认关闭。

所有命令均可在 NVDA “按键与手势”对话框的“窗口状态”类别中重新分配。

## 系统要求

- NVDA 2026.1 或更高版本
