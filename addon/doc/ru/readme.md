# Состояние Окна

Дополнение для NVDA, позволяющее запрашивать состояние текущего активного окна.

## Проблема

NVDA не сообщает, развёрнуто ли окно во весь экран, восстановлено или привязано к краю экрана при запросе названия. Эта информация полезна, потому что:

- Нажатие комбинации клавиш Windows+стрелка вверх для развёртывания окна на весь экран может вместо этого активировать средство выбора расположения окон в Windows 11, в результате чего окно останется в неизвестном состоянии.
- Зрячие пользователи могут бегло взглянуть на окно, чтобы оценить его размер и положение. Незрячие пользователи не имеют аналогичной возможности проверить это, не попытавшись изменить размер окна и не прислушавшись к тому, что сообщает NVDA.
- JAWS включает эту информацию в своё объявление по нажатию JAWS+T. NVDA этого не делает.

## Что делает это дополнение

1. **NVDA+Shift+T**: Сообщает о состоянии текущего активного окна. Возможные состояния:
   - Развёрнуто
   - Восстановлено (обычный оконный режим)
   - Свёрнуто
   - Прикреплено слева, прикреплено справа, прикреплено сверху, прикреплено снизу (снимки половины экрана)
   - Верхний левый угол, верхний правый угол, нижний левый угол, нижний правый угол
   - Левая треть, средняя треть, правая треть (третьи в режиме привязки к окнам Windows 11)
   - Две трети слева, две трети справа (две трети в режиме привязки Windows 11)
   - Неизменяемый размер (для окон, таких как рабочий стол, которые нельзя развернуть на весь экран или восстановить)

2. **Необязательно: улучшение NVDA+T**: При включении этой функции в настройках, нажатие NVDA+T будет озвучивать заголовок окна, а затем его состояние, например, "Firefox, развёрнуто". Это соответствует поведению JAWS. Двойное нажатие NVDA+T для фонетического объявления заголовка и тройное нажатие для копирования его в буфер обмена не затрагиваются.

## Настройки

Откройте настройки NVDA > Состояние окна, чтобы выполнить следующие действия:

- **Добавить состояние окна к объявлению названия NVDA+T**: Если этот параметр включен, NVDA+T отображает состояние окна после заголовка. По умолчанию отключено.

- **Сообщить номер дисплея вместе с состоянием окна**: Если этот параметр отмечен, за состоянием окна следует номер дисплея (например, "восстановлено, на дисплее 1"). Полезно при работе с несколькими мониторами. По умолчанию отключено.

Все команды можно переназначить в диалоге жестов ввода NVDA в категории "Состояние окна".

## Требования

- NVDA 2026.1 или выше
